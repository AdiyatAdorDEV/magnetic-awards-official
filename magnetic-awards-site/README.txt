MAGNETIC AWARDS WEBSITE — VS CODE
=================================

OPEN:
1. Extract magnetic-awards-website.zip.
2. In VS Code, choose File > Open Folder and open magnetic-awards-site.
3. Open index.html.
4. Preview using Chrome/Edge or the VS Code Live Server extension.

MANAGE AWARDS:
Scroll to "Manage the awards" near the bottom of the Awards section.
- Add a new award by entering its name, month/category, caption, and picture.
- Use Edit to change an existing award's title, category, caption, or picture.
- Use Delete to remove an award.
- Award data is saved in IndexedDB in this browser, so it remains after refresh.

IMPORTANT:
This is local browser storage only. It does not publish edits to all visitors. To let everyone see new awards on a hosted website, connect a backend/database and an admin login.
Images must be under 8 MB.
